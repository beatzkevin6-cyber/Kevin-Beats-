# Kevin Beats — Official Beat Store

Boutique statique responsive pour les instrumentales Kevin Beats.

## Publier avec GitHub Pages

1. Ouvrez **Settings** dans le dépôt GitHub.
2. Allez dans **Pages**.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main` et le dossier `/ (root)`.
5. Cliquez sur **Save**.

## Personnalisation

- Modifiez les instrumentaux dans `script.js`.
- Modifiez les styles dans `styles.css`.
- Genres : Amapiano, Afrobeat, Dancehall et Shatta.
- Le bouton d'ajout utilise la licence Basique à 10 $.
- Le paiement est remplacé temporairement par une demande par e-mail.
